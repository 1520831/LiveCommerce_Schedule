# 라이브커머스 편성표

현대Hmall 쇼라, CJ 라이브쇼, 카카오 쇼핑라이브의 시간대별 편성을 한 화면에서 봅니다.

**→ https://1520831.github.io/LiveCommerce_Schedule/**

하루 네 번(07:00 / 12:00 / 18:00 / 23:30 KST) 자동으로 갱신됩니다.

## 보는 법

- 날짜는 위쪽 `‹ ›` 또는 날짜 칩으로 옮깁니다. 방향키 ←→ 도 됩니다.
- `전체 / HD / CJ / KA` 로 채널을, `전체 / 본방 / 재방` 으로 재방송 여부를 거릅니다.
- **방송을 누르면 상품 페이지가 열립니다.**
- `▼ 소구 문구` 를 누르면 방송별 홍보 문구가 한 줄 더 나옵니다.
- 우상단 `?` 에 재방송 판정 기준과 표시 규칙을 적어뒀습니다.

## 이 저장소에 든 것

```
index.html   뷰어
data/        편성 데이터 (수집 결과)
```

수집기와 문서는 별도 비공개 저장소에 있습니다. 이 저장소에는 **뷰어와 데이터만**
자동으로 배포됩니다.

## 데이터에 대해

- 편성은 임박해서 등록됩니다. **3~4일 뒤부터 건수가 적은 것이 정상**이고 수집
  실패가 아닙니다.
- 현대 방송명은 방송이 나가기 전에만 받을 수 있어서, 수집이 돌기 전에 이미 나간
  방송은 `방송명 미확보` 로 표시됩니다.
- 재방송 표시는 채널마다 근거가 다릅니다. 자세한 기준은 뷰어의 `?` 버튼에
  있습니다.
- CJ 카테고리 배지는 CJ 공식 분류명이 아니라 상품을 보고 붙인 이름입니다.

각 사의 편성은 예고 없이 바뀔 수 있습니다. 정확한 정보는 각 사 공식 채널을
확인하세요.
